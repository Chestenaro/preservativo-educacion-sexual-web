# Educación Sexual Web - Guía de Preservativos

Una página web interactiva (Single Page Application) diseñada para brindar información clara, interactiva y accesible sobre el uso adecuado de los preservativos (masculinos y femeninos), sus características y pasos de colocación.

## 🚀 Características

- **Diseño interactivo:** Selección visual entre preservativo masculino y femenino.
- **Vista detallada y modales:** Explicación paso a paso de uso y recomendaciones.
- **Single Page Application (SPA):** Navegación fluida y rápida sin recargas de página.
- **Diseño Responsive:** Adaptado para visualizarse correctamente en computadoras, tablets y celulares.

## 🛠️ Tecnologías utilizadas

- **HTML5:** Estructura semántica de la web.
- **CSS3:** Estilos personalizados, variables CSS, gradientes y diseño flexible.
- **JavaScript (Vanilla):** Lógica de navegación SPA y manipulación del DOM.
